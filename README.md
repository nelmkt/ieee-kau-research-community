# Research Community | IEEE KAU Student Branch

Landing page for the IEEE KAU Student Branch Research Community at King Abdulaziz University.

Live site: https://nelmkt.github.io/ieee-kau-research-community/

It's a single static `index.html` (no build step), deployed with GitHub Pages from the `main` branch.

To update the membership link, find `join-btn` in `index.html` and set its `href` to the registration form URL.

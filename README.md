# Research Community | an IEEE Group

Landing page for the Research Community of the IEEE KAU Student Branch, open to students and researchers everywhere.

Live site: https://nelmkt.github.io/ieee-kau-research-community/

A single static `index.html` (no build step), deployed with GitHub Pages from the `main` branch. English and Arabic are both built in; the Arabic text lives in the `AR` object at the bottom of the file.

## Registration links

When the forms are ready, set these `href` values in `index.html`:

- `id="join-btn"`: member registration form
- `id="team-btn"`: team application form
- each `class="apply"` link in the "Join a team" section: the team application form (optionally one per team)

Then remove the "Registration opens soon." line.
